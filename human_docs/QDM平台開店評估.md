# QDM 平台開店評估：3D 列印店面

> 整理日期：2026-09-09
> 資料來源：[官方方案頁](https://qdm.tw/plan)、[方案功能表 PDF](https://cdn.qdm.cloud/assets/download/QDM_plan_features_highlights.pdf?v=250101)（2025-01 版）、[說明中心](https://help.qdm.tw)、[常見問題](https://qdm.tw/faq)
> 用途：評估在 QDM 架設 3D 列印商品店面的功能彈性、免費版限制，以及與 Agent／GitHub 的協作方式。

---

## 結論

**QDM 很適合先把 3D 列印店「開起來賣」。** 視覺與行銷彈性不小；但它是託管式開店後台，不是你自己擁有整份網站程式。

和 Agent、GitHub 的最佳關係是「本地管素材與客製碼，後台負責上線」，不是把 QDM 當成可 `git clone` 的專案。

---

## 1. 功能面：平台對店面的控制彈性

QDM 的彈性主要在**外觀與行銷**，不在**核心交易架構**。

### 1.1 能高度控制的部分

官方強調沒有固定套版，用區塊堆商店。免費方案也能用這些（方案表寫「不限方案通通讓你用」）：

| 層級     | 能做什麼                                             |
| -------- | ---------------------------------------------------- |
| 品牌外觀 | Logo、配色、背景、置頂通知、跑馬燈                   |
| 版面結構 | 內容區塊、商品集合區塊（最新／推薦／暢銷／即將開賣） |
| 程式客製 | 全站自訂 HTML／CSS／JS、HTML 自訂語法區塊、自訂頁面  |
| 內容站   | 部落格、最新消息、公告、留言板、YouTube              |
| 行銷     | 限時特賣、滿額折扣、優惠券、紅利、加價購、免運       |
| 會員     | Email／手機註冊、FB／LINE／Google 登入、分級、標籤   |
| 金物流   | 綠界、藍新、LINE Pay、超取、宅配等（金流費另計）     |
| 追蹤     | GA4、GTM、Meta 像素、Google Ads                      |

官方甚至教：後台沒欄位時，用瀏覽器檢查元素，把 CSS 貼進「版面 > 自訂商店 CSS」。顏色、大小、間距，找得到 selector 就能改。

### 1.2 彈性的天花板

這不是 Shopify 那種「整份 theme 是你的程式」。你改的是**注入片段**，不是整站原始碼。

**很難或做不到的：**

- 重寫結帳、購物車、會員登入流程
- 換掉商品資料模型（規格、庫存、運費計算）
- 用 Git 部署主題（沒有 theme 倉庫）
- 免費方案用 API 同步商品／訂單
- 保證平台改版後，你的自訂 CSS／JS 永遠不壞

### 1.3 對 3D 列印店的實務含義

一般賣法通常夠用：

- 材質／顏色／尺寸 → 用「購物選項」
- 客製說明 → 自訂頁面 + HTML
- 報價流程 → 表單或 LINE

若需要「上傳 STL、自動估價、依模型算價」，QDM 內建購物車撐不住，要外掛表單，或升級後用 API 自己做估價頁。

**一句話：外觀可以很像品牌官網；交易引擎仍是 QDM。**

## 2. 功能面：免費版（共享者）限制

註冊後預設就是這個方案。沒成交不收費；成交後抽 **運費以外金額的 5%**。金流手續費（信用卡常見約 2.0–2.8%）是金流商收，不是 QDM。

| 項目         | 共享者（免費）        | 創作室 $350/月 | 品牌商 $5,000/月 |
| ------------ | --------------------- | -------------- | ---------------- |
| 成交手續費   | 5%                    | 2%             | 0%               |
| 上架商品     | **25 件**       | 300            | 無上限           |
| 獨立網域     | **設定費 $500** | 免費綁定       | 免費綁定         |
| QDM-API      | **無**          | 有             | 有               |
| 大量商品匯入 | **無**          | 有             | 有               |
| 批次功能     | **無**          | 有             | 有               |
| 獨立網域     | 設定費**$500**       | 免費           | 免費             |
| 單一商品圖    | 最多 5 張  |  最多 10 張 | （方案頁未再限）|
| 多國語系    | 不提供 | 可用 |  可用 |

### 2.1 其他要注意的限制

- **三個月沒登入後台，商店可能被收回**
- 網址先是 `你的店名.qdm.tw`；自有網域在免費方案要付轉址設定費
- 官方說法：除批次與 API 外，其餘功能都能用（含 HTML／CSS／JS、促銷、會員、金物流）
- 成交手續費隔月 15 日開帳單

### 2.2 對 3D 列印店最容易撞牆的點

**25 件商品**通常是最先撞牆的：PLA／PETG／樹脂 × 顏色 × 尺寸，很容易超過。

變通做法：少 SKU，把規格放在同一商品的「購物選項」裡，而不是每色一筆商品。

### 2.3 何時該升級

粗算：月成交（扣運費）約 **$7,000 以上**，創作室的年費 $4,200 + 2% 往往比一直抽 5% 划算。

官方建議：

- 創作室：月營收約 5–20 萬
- 品牌商：月營收約 20 萬以上

## 3. 實作／維護：怎麼跟 Agent 協作最方便

QDM 沒有「把商店當 repo 打開」這件事。Agent 幫不上後台點擊，但很適合當**前端與內容工廠**。

### 3.1 建議工作流

在本機專案（`3d-print-shop-v2`）當**素材與客製碼倉庫**，QDM 只當上線目標：

```
本機專案（給 Agent）          QDM 後台（你貼上）
─────────────────          ────────────────
css/store.css       →      版面 > 自訂商店 CSS
js/store.js         →      版面 > 自訂 JS
pages/about.html    →      頁面 > 自訂頁面 > 原始碼
pages/custom.html   →      客製／估價說明頁
snippets/           →      HTML 自訂語法區塊
copy/products.md    →      商品文案、SEO
docs/qdm-map.md     →      每段碼要貼到哪個後台路徑
```

### 3.2 對 Agent 下指令時要講清楚的三件事

1. **貼到哪**：例如「這段只進全站 CSS，不要寫成獨立網站」
2. **選擇器限制**：能改外觀，不能重寫結帳
3. **驗收方式**：你貼上後截圖／給網址，再叫 Agent 修

### 3.3 適合／不適合交給 Agent 的工作

**適合：**

- 首頁區塊 HTML
- 品牌 CSS
- 商品頁樣式
- 關於我們／列印流程／材質說明頁
- SEO 文案、優惠活動文案

**不適合直接做：**

- 金流申請
- 運費規則
- 發票
- 訂單狀態

這些在後台設定，沒有程式可 commit。

免費方案沒 API，Agent **無法**自動同步商品或訂單。升級創作室後，才值得做「本機商品表 → API 上架」這類自動化。

## 4. 實作／維護：適不適合跟 GitHub 連動

**適合作「工作檔」連動，不適合作「QDM 官方專案」連動。**

QDM 不像 Shopify 有 Theme GitHub 整合。GitHub 連了也不會自動部署到商店。

### 4.1 仍然建議開 GitHub 的原因

- 後台貼上的 CSS／JS **沒有版本史**，一改壞全站很難回溯
- Agent 需要穩定的檔案當上下文
- 文案、材質表、價格表、品牌規範值得版本化
- 之後若升級 API，整合腳本本來就要進 repo

### 4.2 何時不需要

如果只打算用後台填商品、幾乎不寫自訂碼，GitHub 邊際效益低。

### 4.3 較務實的切法

| 做法                                             | 何時選                                             |
| ------------------------------------------------ | -------------------------------------------------- |
| **QDM + 本機 snippet repo + GitHub**       | 現在就要賣、要品牌感、SKUs 還可控                  |
| **自架網站（Next.js 等）+ 之後串 QDM API** | 要上傳模型、自動估價、高度互動；且已升級創作室以上 |
| **完全自架金物流**                         | 控制欲最高，但維護成本也最高，初期通常不划算       |

---

## 5. 建議路線

對這個 3D 列印店：

1. **先用 QDM 免費方案開店**，驗證有沒有單。
2. **本機專案 + GitHub 只管客製碼與文案**。
3. 商品快到 25、或需要匯入／API 時，再升創作室。
4. 不要一開始就把 QDM 當可以 `git push` 上線的網站。
