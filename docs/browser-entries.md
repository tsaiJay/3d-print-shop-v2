# 瀏覽器協作入口

這間店的前台與後台入口。給 agent 用瀏覽器一起改頁面時先看這份。貼碼位置與選擇器仍以 `docs/qdm-layout-reference.md` 為準；那份不含商店網址，可換帳號沿用。

**不要**把後台 `token`、cookie、帳號或密碼寫進 repo、commit 或聊天紀錄。網址列上的 `token=` 是當次登入憑證，過期就失效，只存在瀏覽器分頁裡。

---

## 前台

- 入口：<https://tsaijlab.qdm.tw/>
- 目前頁面標題：你的商店名稱（尚未改店名）
- 看版面、點選單、核對改完的畫面：直接開這個網址，不需登入
- 頁首「會員登入」是顧客帳，不是後台。改頁面時不要去登顧客帳

## 後台

- 入口：<https://tsaijlab.qdm.tw/admin/>
- 登入後看板路徑：`/admin/index.php?route=common/home`（後面的 `token` 由平台帶，不要抄下來）
- 登入成功的標題形如：`後台 - 你的商店名稱 :: 看板(Dashboard)`
- 目前帳號角色：共享者・SHARER
- 看得到的主選單：商品、促銷、頁面、版面、擴充
- 看不到訂單、會員、商店設定、金物流。那些先不要點、不要猜路徑

右下角「QDM 開店顧問」是客服聊天，不要操作。頂部「登出」不要點。

---

## 用瀏覽器一起改時

1. 先列出現有分頁。網址已是 `tsaijlab.qdm.tw` 或後台看板的，沿用，不要再開一個新登入。
2. 前台改完要在前台分頁核對；後台編輯留在後台分頁。兩邊都在時，不要互相覆蓋或關掉。
3. 後台若變成登入頁（要填帳號／密碼，或被導到登入），**停下來問使用者**。不要猜密碼，不要試登入。
4. 使用者說已登入後，再從現有後台分頁繼續；不要把新的 `token` 寫進檔案。
5. 只操作任務需要的畫面。未開通的模組先不動。
