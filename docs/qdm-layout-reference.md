# QDM 網頁編排參考（可換帳號沿用）

這份文件整理可貼 HTML／CSS／JS 的位置，以及官方說明裡對前台結構的寫法。不含商店網址、登入帳號、token 或任何店家個資。

貼上位置、編輯器欄位、選擇器與官方語法對 QDM 前台是通用的，不綁特定帳號。第 2 節的後台選單則是「能進商品、促銷、頁面、版面、擴充，沒有訂單／會員／商店設定／金物流」這種權限會看到的範圍，不是店長完整後台，也不是平台某個正式角色名稱。

官方知識庫：<https://help.qdm.tw/support/home>  
官方首頁：<https://qdm.tw>

不確定平台能不能做時，先查知識庫，不要猜平台 API。QDM 是託管式開店後台：能改外觀與注入片段，不能改結帳、購物車、金物流核心。

## 1. 怎麼改前台（先選貼上位置）

優先順序：

| 優先 | 後台路徑 | 適合做什麼 | 作用範圍 |
| --- | --- | --- | --- |
| 1 | **頁面 > 自訂頁面** → 編輯器「原始碼」 | 單頁 HTML、該頁 `<style>`、該頁 `<script>`、輪播、滿版、錨點、iframe | 單一自訂頁 |
| 2 | **商品 > 上架商品** → 商品介紹「原始碼」 | 商品頁圖文排版 | 單一商品 |
| 3 | **商品 > 商品分類** → 頁面樣式 → 商品分類頁上方圖文區塊「原始碼」 | 分類頁頭圖／輪播／影片 | 單一分類頁 |
| 4 | **版面 > HTML 自訂語法區塊** | 可指定版面（首頁、商品、目錄、自訂頁面…）與位置（置頂／底部／左欄／右欄）的 HTML 區塊、彈跳視窗 | 指定版面＋位置 |
| 5 | **版面 > 商店頁尾 > 延伸資訊「原始碼」** | 頁尾右側文案、固定訊息按鈕 | 全站頁尾 |
| 6 | **版面 > 自訂 CSS 商店樣式** | 全站覆寫顏色、間距、隱藏、滿版、按鈕 | **整間商店** |
| 7 | **版面 > 自訂 JS 全站程式碼** | 全站行為、載入外部 JS、補官方語法 | **整間商店** |

原則：

- 單頁效果先放在該頁「原始碼」，不要一開始就寫進全站 CSS／JS。
- 選擇器要盡量限定範圍（例如 `body.product-product`、自訂 class），避免蓋掉平台全域元件。
- 片段要小而完整、可直接複製貼上；不要依賴本機 bundler。
- 後台沒有欄位時，官方做法是：前台右鍵「檢查」→ 試改 CSS → 成功後貼到 **版面 > 自訂 CSS 商店樣式**。

## 2. 後台選單（此權限看得到的範圍）

左側主選單為：**商品、促銷、頁面、版面、擴充**。店長帳號通常還會有訂單、會員、設定、金物流等，那些不在這份編排參考的範圍。看不到的模組先不動；真的需要時再請店長開權限。

頂部另有知識庫／店手冊連結，以及前台預覽入口。右下角「QDM 開店顧問」是客服聊天，編輯頁面時不要操作。

### 2.1 商品

| 選單 | 用途（編排相關） |
| --- | --- |
| 圖庫與上傳 | 圖片資產；產生前台圖片 URL |
| 上架商品 | 商品圖、名稱、特色、**商品介紹（CKEditor／原始碼）** |
| 商品分類 | 主選單來源；分類頁「頁面樣式／上方圖文區塊」 |
| 購物選項 | 規格選項（顏色、尺寸等）呈現，可用 CSS 調整 |
| 標籤管理 | 商品標籤 |
| 品牌管理 | 品牌頁 |
| 商品評論 | 前台評論顯示 |

### 2.2 促銷

快捷入口：全館滿額(件)、紅標配綠標、訂單滿額(件)、訂單滿額贈、商品任選(件)、商品限時特賣、商品加價購、瀏覽所有促銷套件。

編排上較常碰到：限時特賣倒數、加價購樣式、促銷活動頁顏色。這些多半用全站 CSS／JS 或官方語法，不是另做獨立網站。

### 2.3 頁面

| 選單 | 用途 |
| --- | --- |
| 商品目錄頁 (Category) | 連到商品分類（與「商品 > 商品分類」同一處） |
| 自訂頁面 (Page) | 自訂 HTML 頁；前台路徑形如 `/pages/{id}`，可用 SEO 友善網址 |
| 小紅自訂頁面 (Page LittleRed) | 小紅／KOL 導購用自訂頁，與一般自訂頁分開管理 |
| 部落格 (Blog) | QDM 內建部落格；也可 iframe 嵌進自訂頁 |
| 最新消息 (News) | 消息列表／內文編輯器（可貼原始碼與 `<style>`） |
| 最新公告 (Notice) | 公告內容 |

### 2.4 版面

**風格**

- LOGO / 導覽列 / 配色 / 背景
- 自訂 CSS 商店樣式
- 自訂 JS 全站程式碼

**版面區塊**

- HTML 自訂語法區塊
- 共用橫幅管理 (Banner Manager)
- 幻燈片滑塊橫幅 (Slideshow)
- 水平並排橫幅 (Carousel)
- 輪播橫幅 (Banner)
- 瀏覽所有版面區塊套件（等同擴充套件目錄裡的版面分類）

**導覽選單**

- 商店主選單 (Header Menu) → 實際是商品分類樹
- 商店頁尾 (Footer Menu)

### 2.5 擴充

快捷：共用橫幅、LINE／Facebook／Google 登入、Facebook 廣告、Google Ads、瀏覽所有商店擴充套件。

完整目錄見第 6 節。版面相關套件都在「版面 內容區塊」與「版面 商品集合區塊」。

## 3. 各編輯畫面要記的欄位

### 3.1 自訂頁面

路徑：頁面 > 自訂頁面。列表欄位：ID、頁面標題、前台連結、排序、狀態。可新增／刪除／編輯。系統常預設有「關於我們」「服務條款」這類頁。

編輯分頁：

**一般**

- 頁面狀態：啟用／停用
- 頁面標題
- 頁面內容：CKEditor。工具列含「加入多張圖片」「最大化」「**原始碼**」、圖像、表格、錨點、對齊、字型、顏色等

**SEO與排序**

- SEO 友善網址（避免純數字、`-`、`&` 等特別符號；可中英混數字）
- SEO 短描述（meta og:description）
- 網站頁尾顯示 (Footer)：是否出現在頁尾「自訂頁面」列表
- 排序

貼代碼時一律切「原始碼」。官方單頁滿版、輪播、錨點、嵌入影片／表單都走這裡。

### 3.2 自訂 CSS 商店樣式

路徑：版面 > 自訂 CSS 商店樣式（畫面標題「DiY 自訂樣式 CSS」）。

- ACE 程式碼編輯器
- **立即發佈**（不是一般「儲存」）
- **記錄**：CSS 編輯記錄
- 語法套用**整間商店**
- 平台不提供代客撰寫 CSS

改完請用無痕視窗看前台（配色頁也提醒瀏覽器快取）。

### 3.3 自訂 JS 全站程式碼

路徑：版面 > 自訂 JS 全站程式碼（畫面標題「自訂程式碼 SCRIPT」）。

後台原文重點：

1. 不要貼來路不明的 JavaScript。
2. **不要寫 `<script>` 標籤**。這裡的程式會自動打包，以外部檔案方式載入。
3. 載入外部 JS 請用 `jQuery.getScript()`。
4. 系統已內建 **jQuery 2.2.4**，不必再載一次。

操作同樣有發佈與「JavaScript 編輯記錄」。

對照：自訂頁／商品介紹「原始碼」裡**可以**放 `<script>`（官方輪播、倒數、iframe 高度都這樣寫）。全站 JS 欄位則不行。

### 3.4 HTML 自訂語法區塊 (Html/CSS Box)

路徑：版面 > HTML 自訂語法區塊。可新增多個區塊，每個區塊有：

- 區塊名稱（僅後台頁籤辨識）
- **版面**：首頁、商品、目錄、會員、自訂頁面、留言板、結帳、最新消息、最新公告、任選或滿額活動、購物車
- **位置**：置頂、底部、左欄、右欄
- 狀態、排序
- 內容：CKEditor／原始碼

後台提示內建能力：

- RWD：Bootstrap **v3.2.0**
- 視差／進場：WOW.js + Animate.css（例如 `class="wow slideInRight"`）
- 彈出視窗：fancyBox 3
- 表格：可用外部產生器，width 設 100%

部分套件可再限制只出現在指定自訂頁面（知識庫「套件版面可以限制露出在指定的自訂頁面」）。

### 3.5 LOGO / 導覽列 / 配色 / 背景

路徑：版面 > LOGO / 導覽列 / 配色 / 背景。五個分頁：

**導覽列（桌面版四款）**

- 基本款：固定頁頂，適合各種比例 LOGO，聯絡資訊折疊
- 簡潔款：適合長型 LOGO
- 攤列款：適合方型或較高 LOGO，資訊攤列
- 選單款：固定頁頂、長型 LOGO、合併主選單（選單較少時）

手機版導覽與桌面不同；改手機購物車／Menu 圖示顏色要靠自訂 CSS。

**LOGO**

- 商店 LOGO（桌面版）
- 商店 LOGO（手機版）：建議高度 56px；GIF／PNG／JPEG
- favicon：正方形 PNG，建議 48×48

**背景**

- 手機固定白色背景
- 桌面：圖樣平鋪，或大圖滿版（官方建議約 1920×1280、1MB 以下）

**配色**

- 頁首：手機置頂列漸層／文字；電腦 Header 背景圖（Cover 或 Parallax）、自訂高寬
- 頁尾：文字、連結、選單背景、Copyright 背景
- 勾選「啟用自訂顏色」後才套用下方色票（LOGO 區、社群列、置頂列、主選單、下拉、跑馬燈、本文、按鈕、商品名稱／價格／特賣圖章）
- 請用無痕模式檢查

**版面**

- 商店 LOGO 靠左／置中
- 首頁左右滿版（寬度 100%）
- 選單款置頂社群：Facebook、LINE、YouTube、Instagram、Pinterest、Tumblr、Twitter
- 商品集合水平捲動／自動輪播秒數（暢銷、最新、特賣、相關）
- 商品頁：介紹用頁籤或折疊、商品左右滿版、名稱位置、放大鏡在右邊或覆蓋、隱藏 QR、隱藏側欄箭頭、隱藏願望清單／比較

能用後台選項解決的，先不要寫 CSS。

### 3.6 橫幅三步驟

1. **版面 > 共用橫幅管理**：新增橫幅、上傳 2 張以上才會輪播、可設連結。
2. **擴充／版面區塊** 開通：幻燈片滑塊、水平並排、或輪播橫幅。
3. 在套件裡指定桌面／手機可用不同橫幅、版面位置、啟用、上下架時間。

建議尺寸（72dpi）：

| 用途 | 建議 |
| --- | --- |
| LOGO | 425×150，透明 PNG |
| 滿版輪播／幻燈片 | 寬 1920，高不限 |
| 非滿版輪播／幻燈片 | 寬 1170，高不限 |
| 水平並排（三張） | 寬 390，高不限 |
| 商品圖 | 960×960（上架建議也可 2048×2048） |
| 同一區塊多圖 | 尺寸必須一致 |
| 檔案 | 2MB 以下；JPG／PNG／JPEG；檔名避免特殊符號 |

另有「背景全版幻燈片」套件（擴充 > 背景全版幻燈片）。

### 3.7 商店頁尾

路徑：版面 > 商店頁尾。欄位分組：

- 自訂頁面（對應自訂頁「網站頁尾顯示」）
- 客戶服務
- 其他服務
- 會員中心
- **延伸資訊**：CKEditor／原始碼，顯示在頁尾最右側（地址、Slogan、固定訊息按鈕）

各連結可切換顯示中／編輯。浮動客服按鈕官方建議貼在延伸資訊最下方。

### 3.8 商品介紹與分類頁圖文

- 商品介紹：上架商品 > 編輯 > 商品介紹，切「原始碼」。圖片單張建議 1MB 以下。
- 分類頁頭圖：商品分類 > 編輯 > **頁面樣式** > **商品分類頁上方圖文區塊** > 原始碼。可放官方輪播圖／影片語法。
- 分類還可設目錄頁「圖片模式／快選模式」，並作為主選單。

### 3.9 最新消息

內文編輯器可在最上方貼 `<style>`。官方手機字級範例針對 `.content-news .style1`，段落要有 `class="style1"` 才會套到。

## 4. 前台技術與常用選擇器

前台大致是 **Bootstrap 3.2** + **jQuery 2.2.4**，另常見 lightSlider、fancyBox 3、WOW.js、Animate.css。倒數可用官方 CDN：`https://cdn.qdm.cloud/assets/js/jquery.countdown.2.2.0.0.min.js`。

RWD class（後台原文）：

```html
<div class="visible-xs visible-sm">僅手機顯示</div>
<div class="hidden-xs hidden-sm">僅桌面顯示</div>
<div class="col-xs-12 col-md-6">手機整列、桌面一半</div>
```

官方文件出現過的結構／選擇器（覆寫前仍應在前台「檢查」確認）：

| 選擇器 | 常見用途 |
| --- | --- |
| `#body-outer-container`、`#body-outer-container > .container-inner`、`#maincontent` | 自訂頁內文滿版 |
| `#content-wrapper > .container`、`.container-inner` | iframe／滿版去 padding |
| `body.product-product` | 限定商品頁 |
| `a#button-cart`、`#button-quick-checkout` | 加入購物車、直接購買 |
| `.checkout-cart #button-next-checkout` | 購物車下一步 |
| `#terms-wrapper #button-payment-method` | 結帳同意後的進行結帳 |
| `#options .control-group > label.radio` / `label.checkbox` | 購物選項 UI |
| `.grid-box .image a, .grid-box .name a` | 目錄商品卡連結 |
| `#mobile-navbar ... .shopping-cart .fa`、`#menu-btn span` | 手機購物車／選單圖示 |
| `.content-news .style1` | 最新消息字級 |
| `.display_price` | 加價購顯示原價 |
| `header`、`#footer` | 頁首／頁尾 |

商品頁 body 常有 `product-product` 這類 class，全站 CSS 請用它限定範圍。

官方單頁滿版 CSS（貼在該自訂頁原始碼的 `<style>`，不要輕易丟進全站 CSS）：

```css
#body-outer-container {
  width: 100%;
  padding-left: 0;
  padding-right: 0;
}
#body-outer-container > .container-inner,
#maincontent {
  padding: 0;
}
```

## 5. 寫片段時的慣例

**HTML（CKEditor 原始碼）**

- 自訂區塊加專屬 class／id，例如 `shop-hero`、`print-spec`。
- 圖片先上傳圖庫再插入；編輯器插入的圖走商店 `/image/` 路徑，並常帶 `onerror="imgError(this);"`。
- 輪播初始化官方常用頁內 `function init_inline() { ... lightSlider ... }`。
- 倒數的 id 不要用 `countdown_dashboard`（會跟商品頁衝突），請自訂英文名。

**CSS（全站）**

- 先用瀏覽器試改，再貼上。
- 需要時才加 `!important`。
- 手機斷點可參考官方：`@media (max-width: 1000px)` 或 `max-width: 768px`。

**JS（全站欄位）**

- 只貼純 JS，不要 `<script>`。
- 用 `if ($('#某個元素').length)` 包起來，避免每頁都報錯。
- 外部檔：`jQuery.getScript("https://...")`。
- 官方註明部分語法「非系統內建、不保證全裝置正常」。

**不要做**

- 不要覆蓋結帳送出、金流、物流表單的核心行為。
- 不要在全站 JS 載入不明第三方腳本。
- 不要改平台全域 `.container` 卻不限定頁面，以免目錄／結帳一起壞掉。

## 6. 擴充套件裡跟版面有關的項目

**版面 內容區塊**

- HTML 自訂語法區塊
- 幻燈片滑塊橫幅、水平並排橫幅、輪播橫幅
- 跑馬燈、初訪彈出視窗
- 側邊商品快篩器、游標互動換圖、浮動側邊廣告
- 產品圖放大鏡、Youtube 影音
- 背景全版幻燈片、側邊目錄、置頂通知列

**版面 商品集合區塊**

- 推薦商品、最新商品、特賣商品、暢銷商品
- 即將開賣、隨機商品、相關商品
- Flickr（停止維護）

這些套件通常要設：版面、位置（置頂／底部／左欄／右欄）、排序、狀態。同一位置多個套件時，用排序決定由上到下。最新／暢銷等是否水平捲動，在「風格 > 版面 > 擴充套件」。

其餘分類（賣點體驗、OMO、LINE／Meta／Google、促銷、導流、會員、出貨、安全）多半不是頁面 HTML 的主戰場；要用再查知識庫對應文章。

## 7. 圖庫與檔名

路徑：商品 > 圖庫與上傳。

- 單張 ≤ 2MB；長或寬 ≤ 16000px
- 僅 JPG／PNG／JPEG（前台可能自動轉 WebP）
- 資料夾與檔名避免中文與 `-`、`&` 等符號（Facebook 分享、URL 編碼容易出事）
- 單次最多 30 張；單夾建議不超過 1000 張
- 上傳後路徑即固定：後台不能改檔名、不能搬資料夾，改了會讓前台舊連結失效
- 要進資料夾請先打開該資料夾再上傳

Banner 與商品圖限制見 3.6、3.8。

## 9. 建議工作流程

1. 先決定要改的是「單一自訂頁／商品／分類」還是「全站」。
2. 能用風格分頁、橫幅套件、商品集合套件就先用後台選項。
3. 需要自訂結構時，在本 repo 用 HTML／CSS／JS 寫成可貼上的小片段（選擇器加前綴）。
4. 圖片上傳圖庫（英文檔名），片段裡用圖庫 URL。
5. 貼到對應後台欄位；單頁用「原始碼」，全站 CSS 用「立即發佈」。
6. 桌面與手機各看一次；配色／CSS 用無痕視窗。
7. 在任務說明標註後台路徑，例如：`頁面 > 自訂頁面 > 原始碼`。

本 repo 只版本控管這些片段與素材，不是可獨立部署的整站。
